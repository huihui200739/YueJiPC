# 商店截图清单

截图必须来自真实可安装版本，不使用界面设计稿冒充运行画面。

## 建议顺序

1. 资料库
   - 展示 PDF 与网页资料混合列表
   - 展示标签、收藏、最近阅读和搜索
   - 避免出现真实姓名、课程账号或版权论文标题

2. 三栏 PDF 阅读工作台
   - 左侧页面缩略图
   - 中间 PDF 页面
   - 右侧证据卡
   - 选用自制测试文档

3. 创建证据卡
   - 显示已选择的原文
   - 显示高亮/下划线、颜色、笔记和标签

4. 来源回跳
   - 显示对应页面和珊瑚色重新突出选区
   - 画面中保留右侧证据卡，直观表达闭环

5. 复习中心
   - 展示待复习、已掌握和标签过滤

6. Markdown 导出结果
   - 展示资料名、页码、引用、笔记和状态

## 画面要求

- 使用 3120 × 2080 或商店要求的 PC 截图尺寸
- 亮色主图至少 4 张，暗色模式可作为补充图
- 统一窗口尺寸和示例数据
- 不展示调试浮层、鼠标悬停残影、个人路径或账号信息
- 图中文字保持可读，不为填满画面而过度缩放
- 如需标题包装，在商店允许范围内使用简短事实描述

## 截图标题建议

- “资料与重点，一处整理”
- “原文、页码和选区一起保存”
- “点击证据，准确回到来源”
- “把阅读重点变成复习清单”
- “带来源导出 Markdown”
