# 两分钟演示脚本

目标时长：1 分 50 秒到 2 分钟。录制真实 HarmonyOS PC 运行画面。

## 0:00-0:12 痛点

旁白：

“阅读论文和课程资料时，我们常把摘录记下来，却忘了它来自哪一页，也很难在复习时快速核对。阅迹把每条重点变成可以返回来源的证据卡。”

画面：

- 启动阅迹
- 展示包含 PDF 和网页资料的本地资料库

## 0:12-0:32 PC 资料库

旁白：

“PDF 可以通过文件选择或直接拖入窗口导入。文件会复制到应用本地，资料库支持搜索、标签、收藏和最近阅读。”

画面：

- 拖入一份自制 PDF
- 编辑资料标题和标签
- 使用搜索或收藏

## 0:32-1:03 证据卡

旁白：

“在三栏工作台中，左侧是页面导航，中间阅读 PDF，右侧整理证据。选择原文后，可以设置高亮或下划线、颜色、笔记和标签。”

画面：

- 搜索关键词并跳到结果
- 鼠标选择一段文字
- 创建带笔记和标签的高亮证据卡

## 1:03-1:22 来源回跳

旁白：

“阅迹不仅保存文字，还保存文件、页码和选区坐标。即使关闭重启，从证据卡点击回到原文，也能重新打开资料、跳到对应页面并突出原选区。”

画面：

- 返回资料库或复习中心
- 点击“回到原文”
- 展示页码和重新突出选区

## 1:22-1:42 复习与导出

旁白：

“证据卡可以标记为待复习或已掌握，也能按标签筛选。整理完成后，可以导出带资料名、页码和网址的 Markdown 学习笔记。”

画面：

- 切换复习状态
- 过滤标签
- 导出并打开 Markdown

## 1:42-1:55 隐私与收尾

旁白：

“阅迹不需要账号，不上传 PDF、摘录或笔记。它希望让每一条学习结论都有出处，也让每一次复习都能回到原文。”

画面：

- 暗色或专注模式
- 应用图标与项目名收尾

## 录制检查

- 使用合法自制测试 PDF 和无隐私示例网址
- 提前关闭通知和无关窗口
- 鼠标移动稳定，避免快速来回
- 旁白先录干净，再按时间点剪画面
- 导出文件路径不要出现真实姓名
- 最终视频不使用未授权音乐
