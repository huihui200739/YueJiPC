# 阅迹隐私政策

更新日期：2026 年 8 月 14 日

生效日期：2026 年 8 月 14 日

阅迹是一款本地优先的 HarmonyOS PC 阅读与学习整理工具。本政策说明阅迹如何处理用户选择导入的资料和在应用中创建的内容。

## 1. 我们处理的信息

阅迹会在设备本地处理以下内容：

- 用户主动选择或拖入的 PDF 文件
- PDF 文件名、页数和阅读位置
- 用户选择的 PDF 原文、页码和选区坐标
- 用户创建的笔记、标签、收藏和复习状态
- 用户主动填写的网页网址、摘录和笔记
- 主题、默认高亮颜色和侧栏状态等应用设置

阅迹不要求注册账号，不收集姓名、手机号、邮箱、身份证件、通讯录、精确位置或设备广告标识。

## 2. 处理目的

上述内容仅用于提供资料管理、PDF 阅读、标注、证据卡、来源回跳、复习和 Markdown 导出功能。

## 3. 存储位置

PDF 副本、数据库和设置保存在阅迹的应用沙箱中。阅迹不运营用于上传或同步这些内容的服务器，应用也不接入广告或第三方分析 SDK。

应用配置已关闭系统级备份恢复能力。阅迹提供用户主动发起的 JSON 结构化备份与恢复：备份包含资料元数据、摘录、笔记、证据卡、主题集合和设置，不包含 PDF 二进制文件；用户选择的目标位置和文件由系统文件选择器管理。网页来源由用户点击后交给系统浏览器打开，浏览器及目标网站的数据处理规则由其各自的隐私政策说明。

## 4. 权限与系统能力

阅迹通过系统文件选择器读取用户明确选择的 PDF，并通过系统文件保存界面导出 Markdown 或 JSON 备份。应用不会扫描用户未选择的目录。

## 5. 信息共享

阅迹不会出售、出租或向开发者服务器上传用户的 PDF、摘录和笔记。只有当用户主动导出 Markdown、导出 JSON 备份或使用系统浏览器打开网址时，内容才会按用户操作离开应用内部存储。

## 6. 保留与删除

资料和证据卡会保留在本机，直到用户在应用中删除对应资料或卸载阅迹。删除 PDF 资料时，阅迹会先创建删除保护快照并暂存 PDF 副本，以便数据库删除失败时恢复，然后删除其沙箱副本和关联证据卡。用户导出的文件由用户自行管理。

## 7. 儿童与未成年人

阅迹面向高校学习场景，不主动收集可识别个人身份的信息。未成年人应在监护人指导下使用设备和第三方网页服务。

## 8. 政策变更

如后续版本新增账号、云同步或其他联网数据处理能力，我们会在功能上线前更新本政策并按平台要求取得授权。

## 9. 联系方式

应用上架前，请将本节替换为 AppGallery Connect 中登记的有效开发者联系邮箱和公开项目地址。
