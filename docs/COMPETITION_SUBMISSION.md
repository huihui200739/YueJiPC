# 赛道三与月度评优表达框架

## 项目一句话

阅迹是一款 HarmonyOS PC 本地阅读工作台，用可追溯证据卡把 PDF 原文、页码、选区、笔记和复习状态连接起来。

## 用户痛点

- 大学生需要同时阅读论文、教材、讲义和网页资料。
- 普通笔记常丢失原始页码和上下文，复习时难以核对。
- PDF 阅读器偏重浏览，笔记工具偏重整理，两者之间缺少可靠来源链路。

## 创新点

1. 统一证据卡
   - 一条记录同时包含原文、资料、页码、选区、笔记、标签和复习状态。

2. 来源回跳
   - 证据卡不是静态摘抄，点击后能返回原页并重新突出原选区。

3. 阅读到复习的闭环
   - 在同一桌面工作台完成导入、阅读、标注、整理、复习和带来源导出。

4. 本地优先
   - 不依赖账号或云端服务，适合论文、教材等敏感或受版权约束资料。

## HarmonyOS PC 特性

- `2in1` 桌面大屏三栏布局
- PDFKit 原生阅读、搜索、文本选区和标注
- 鼠标选区和文件拖放
- 键盘快捷键
- 窄窗口响应式侧栏
- 系统文件选择器、文件保存界面和系统浏览器联动
