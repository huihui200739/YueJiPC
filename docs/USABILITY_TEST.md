# 三人可用性测试记录

不要提前教操作。先给任务，观察完成过程；只有参与者完全卡住时才提示。

## 统一任务

1. 导入指定 PDF 并跳到第 3 页。
2. 搜索一个指定关键词，找到下一处结果。
3. 选择一段原文，创建带“课程重点”标签的高亮证据卡。
4. 给证据卡写一句自己的理解。
5. 关闭并重新打开阅迹，从复习中心返回刚才的原文。
6. 把证据卡标记为已掌握。
7. 添加一条网页资料，保存网址、摘录和笔记。
8. 导出 Markdown 学习笔记。

## 问卷

请按 1 到 5 分评价：

- 我能快速理解资料库、阅读器和复习中心的关系。
- 我能理解“证据卡”和普通笔记的区别。
- 我相信“回到原文”能帮助我核对信息。
- 我愿意在课程阅读或论文阅读中继续使用阅迹。

开放问题：

- 哪一步最让你犹豫？
- 哪个按钮名称不够清楚？
- 你会在什么真实场景使用证据卡？
- 如果只能保留一个功能，你会保留什么？

## 通过标准

- 三人都能完成核心闭环：导入、选区、建卡、重启、回跳
- 核心闭环中位完成时间不超过 5 分钟
- 每人核心闭环求助不超过 1 次
- 连续使用 30 分钟无崩溃
- 发现的 P0/P1 问题在送审前修复
