## 完整描述

阅迹是一款为论文、教材和课程资料设计的 HarmonyOS PC 阅读工作台。

阅读 PDF 时，选择一段原文即可创建证据卡。阅迹会保存原文、页码、选区位置、个人笔记、标签和复习状态。之后从资料库或复习中心点击“回到原文”，即可重新打开资料、跳到对应页面并突出原选区。

主要功能：

- 导入或拖放 PDF 到本地资料库
- 页码跳转、缩放、适应宽度、全文搜索和页面缩略图
- 高亮、下划线和多种标注颜色
- 可追溯证据卡与来源回跳
- 收藏、最近阅读、搜索和标签过滤
- 网页链接、摘录和笔记资料卡
- 待复习与已掌握状态管理
- 导出带资料名、页码或网址的 Markdown 学习笔记
- 亮色、暗色、专注模式和桌面快捷键

阅迹不需要账号，不内置广告，不上传 PDF、摘录或笔记。数据保存在设备本地。

## 审核说明

1. 启动后进入本地资料库。
2. 点击“导入 PDF”，选择审核设备中的普通、未加密 PDF。
3. 在 PDF 中选择文字，右侧会出现证据卡编辑区。
4. 保存证据卡后，点击“回到原文”验证跳页和选区突出。
5. “网页资料”仅保存用户输入，点击来源会调用系统浏览器。
6. 应用没有账号、广告、支付、云同步或后台上传。
